# nexus-windows → nexus-windows-claude

**NexusWindows for Claude** is now published as [`nexus-windows-claude`](https://pypi.org/project/nexus-windows-claude/),
like its sister editions `nexus-windows-codex` and `nexus-windows-antigravity`.

This package only installs `nexus-windows-claude` at the same version, so existing configurations
(`uvx --python 3.14 nexus-windows`) keep working. New installs:

```
uvx --python 3.14 nexus-windows-claude
```

Source, documentation and changelog: https://github.com/pironjulien/NexusWindows-Claude
